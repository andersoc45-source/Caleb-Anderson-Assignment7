Takes a pre-generated list of numbers, multiples evens by two and odds by three. Takes a pre generated list of strings, converts words more than five letters to uppercase while the others to lowercase.

No external files are needed to run this program.

Output:

Processed numbers as a list of numbers

Processed strings as a single string
